# POT BREAKER RE : CBZP v1.0.0 (웹 게임)

같은 `potbreaker` 저장소의 기존 Android v0.16.0 게임을 유지하면서 추가한 새 싱글플레이 미로 추격전입니다.

- 플레이어: CBZP 인턴 고양이 **기묘**; NPC: 악어 **크다 부장**; 감 과장은 화분 랜덤 보충 연출 대상
- 기묘: 모서리에서 랜덤 시작; 맵 전체 확인; 5초당 벽넘기 스택 1회 충전(최대 3), 화분 보유 불필요
- 크다 부장: 맵 중앙 시작; 좌우 150° 시야(정면 10°와 후방 50° 제외), 파티션 시야 차단 없음; 화분이 있어야 최대 3개 벽을 한 번에 돌파, 사용 후 15초 재사용 대기
- 이동 중 기묘가 크다에게 약 5칸 이내로 접근하면 **딸랑딸랑** 표시. 방향은 제공하지 않음
- 화분: 기묘 소지 최대 1개, 크다 최대 2개; 바닥의 획득 가능한 화분 **항상 3개** 유지, 한 개 주우면 한 개 랜덤 보충. 크다의 화분은 충돌 시 우세
- 4컷 만화 오프닝과 승패별 컷신

## 실행

`web/index.html`은 HTML Canvas + Python 게임 로직(Pyodide/WebAssembly)으로 구성되었습니다. Cloudflare Worker는 `cloudflare/worker.js`의 정적 HTML 응답을 제공하며, 브라우저에서 Python 게임 엔진을 실행합니다.

- 웹 최초 실행에는 jsDelivr의 Pyodide 런타임을 다운로드하기 위해 네트워크가 필요합니다.
- 코어 Python 규칙: `web/game.py`
- Python 단독 상태 검증: `python web/game.py`
- PC: WASD/방향키 이동, Shift 벽 넘기, Space 던지기, 마우스로 조준
- 스마트폰: 가로모드 터치 버튼; 화면 터치로 조준·던지기

**주의:** Cloudflare Worker에서는 Python 서버 프로세스를 실행하지 않습니다. Python 로직은 사용자의 브라우저에서 WebAssembly를 통해 실행되며, 화면 입력/그리기는 JavaScript가 담당합니다.
