# POT BREAKER RE v1.0.19

POT BREAKER RE is a single-player browser maze game. The browser runs the Python game engine with Pyodide; the Cloudflare Worker serves the page and engine source.

## Mobile controls

- Use the four-button D-pad to move one direction at a time.
- Tap **대시** to dash and **던지기** to throw a pot.
- The player starts with three pots and can carry up to three.
- Turn the phone sideways before starting. Supported browsers request landscape orientation automatically.
- The touch controls are translucent and kept near the lower corners; the player starts farther inside the field so the controls do not cover them.

## Game feedback

- The player pot is blue, Keuda's pot is red, collectible pots are yellow, and Gamgwajang's pots are green.
- Pot breaks add a short screen shake and a glassy shatter sound.
- Hitting Gamgwajang with the player's pot restores one player HP, up to the three-HP limit. Keuda does not receive that healing.

## Development and release

- Game rules: `web/game.py`
- Browser UI: `web/index.html`
- Worker source: `cloudflare/worker.js` (generated by `scripts/build_worker.py`)
- Engine and mobile UI checks: `python -m unittest discover -s tests -v`

To build the Worker source after changing the game or page, run `python scripts/build_worker.py`.
