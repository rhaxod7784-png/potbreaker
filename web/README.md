# POT BREAKER RE v1.0.24

POT BREAKER RE is a single-player browser maze game. The browser runs the Python game engine with Pyodide; the Cloudflare Worker serves the page and engine source.

## Mobile controls

- Use the four-button D-pad to move one direction at a time.
- Tap **대시** to dash and **던지기** to throw a pot.
- The player starts with three pots and can carry up to three.
- Keep the phone upright; the game screen rotates inside the portrait display automatically.
- The larger touch controls are translucent and kept near the lower corners; the player starts farther inside the field so the controls do not cover them.

## Game feedback

- The player pot is blue, Keuda's pot is red, collectible pots are yellow, and Gamgwajang's pots are green.
- Pot breaks add a short screen shake and a glassy shatter sound.
- Gamgwajang drops mystery pots; Kimyo and Keuda each have a 50/50 chance of losing or restoring one HP when they collect one. Each drop releases two pots at 1.2-second intervals.
- Hitting Gamgwajang with the player's pot restores one player HP, up to the three-HP limit. Keuda does not receive that healing.

## Development and release

- POT BREAKER core: `web/game.py` (`PotBreaker` state and simulation loop).
- Reusable field, combat, and actor components: `web/game_modules.py`.
- Shared Pyodide engine and Ginkgo mode: `web/game_engine.py` (`GameEngine` facade, `GinkgoMode`).
- The Worker builder bundles the Python modules into the single `/game.py` source loaded by Pyodide.
- Browser UI: `web/index.html` for POT BREAKER and `web/ginkgo.html` for Ginkgo.
- Worker source: `cloudflare/worker.js` (generated by `scripts/build_worker.py`)
- Focused pre-QA checks: `python -m unittest discover -s tests -p 'test_game_engine.py' -v` and `python -m unittest discover -s tests -p 'test_potbreaker_engine_modules.py' -v`.
- Ginkgo D1 session and ranking validation remains in `cloudflare/ginkgo-api.js`.

To build the Worker source after changing the game or page, run `python scripts/build_worker.py`.
